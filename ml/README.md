# RakshaPath ML & Intelligence Workspace

Platform: Python (scikit-learn / XGBoost / LLM Extractor)

## Scope
- Road-segment risk estimation model trained on rainfall forecast, historical hazard frequency, and road attributes.
- Model evaluation (precision, recall, baseline comparison on held-out temporal data).
- News-to-hazard extraction pipeline using LLM and Nominatim geocoding.
