# RakshaPath Mobile Application

Platform: Flutter (Android target)
Map Engine: `flutter_map` + OpenStreetMap
State Management & Networking: Provider / Riverpod + Dio / Http

## Scope
- Live route rendering (OSRM) with colored hazard markers and danger zones.
- Trip tracking (location broadcast every 30-60s) and FCM hazard warnings.
- One-press Emergency SOS (Online via Backend, Offline via direct SMS with GPS coordinates).
- Offline contacts and safety status display.
